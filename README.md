# projetosINFO4M
# conexao.php
Nesse código, aprendi a fazer a conexão do PHP com o banco de dados MySQL.
Aprendi a colocar o servidor, usuário, senha e o nome do banco e também a verificar se aconteceu algum erro na conexão. 
# index.php
Nesse código, aprendi a criar uma tela de login usando HTML e PHP.
Aprendi a pegar os dados que o usuário coloca no formulário usando POST, verificar se os campos estão preenchidos e fazer algumas condições com if, else if e else.
Também aprendi a fazer uma consulta no banco de dados para verificar se o e-mail e a senha existem. Depois que o usuário é encontrado,
aprendi a criar uma sessão e guardar informações como o ID e o nome do usuário. 
# protect.php
Nesse código, aprendi a proteger uma página para que somente usuários que fizeram login possam acessá-la. 
Aprendi a iniciar a sessão e verificar se existe um ID de usuário dentro dela. Caso não exista, o acesso à página é bloqueado. 
# painel.php
Nesse código, aprendi a usar o include() para chamar outro arquivo PHP e também a utilizar a proteção criada no protect.php.
Aprendi ainda a mostrar o nome do usuário que está logado usando a informação que foi guardada na sessão. Também foi criado o link para sair da conta. 
# logout.php
Nesse código, aprendi como fazer o usuário sair da conta.
Aprendi a iniciar a sessão, destruir a sessão usando session_destroy() e depois mandar o usuário de volta para a página de login.
